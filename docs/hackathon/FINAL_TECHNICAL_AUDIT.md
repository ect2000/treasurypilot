## Security review and remediation

The independent Standard Codex Security scan of prepatch commit eca8d3c reported one medium/high-confidence CWE-400 finding: anonymous fresh contexts could create unbounded durable worlds and provider work. Scan a09622c9-0757-4c19-a1ed-e0cd01cd4eda is sealed; it was not rewritten to make the original finding disappear. Backend routes/helpers/tests/scripts were reviewed; frontend/binary/doc coverage in that scan was partial.

[Fix report](../security/FIX_REPORT.md) records the shared-boundary correction, test evidence and independent reviewer. That reviewer found a midnight counter rollback and an authentication-to-transport cutoff gap; both were confirmed, fixed and regression-tested. No offensive/load test was run against public services. Measured token totals from the scan include prior thread history/cached context, not an isolated price for this audit.

Remaining limits are material: anonymous users can still consume admission/world Blob reads and exhaust bounded demo quotas. This is not edge DDoS protection or authenticated operator access. The 128 lifetime counter applies to new admissions after this release; pre-existing worlds are not retrospectively counted or deleted. A permanently uncertain action eventually exhausts bounded reconciliation revisions and requires private operator readback/export; its permanent financial claim must never be removed. Local admission-lock uncertainty fails closed. Production banking would require authenticated operators, edge admission controls, a real reservation ledger and broader reconciliation.

Runtime dependency audit reports zero vulnerabilities. The development graph reports five high advisory paths rooted in braces <=3.0.3; no patched version was published at this check. They are linter/development dependencies, not exposed financial runtime inputs. Do not downgrade Next.js to silence them. [Current primary advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).

## Judge challenge and release constraints

Airwallex is essential to real financial observation/execution/readback. The model meaningfully interprets unstructured evidence but does not autonomously invent policy or payment. The current campaign is completed; the live walkthrough demonstrates safe planning/reconciliation, while dated original footage demonstrates exact-approved FX/transfer. Calling that another live payment would be false.

The recording is repeatable in a fresh bounded **planning** context; the financial campaign is never reset. Free-provider availability, API latency, Blob admission limits, indicative-rate drift and browser cookie age can interrupt a take. The runbook documents recovery without fabricating completion. Pre-existing-work competition eligibility and final recording/upload/submission remain unresolved release steps; no organizer message or submission has been sent.
